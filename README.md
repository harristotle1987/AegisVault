# 📜 Sovereign Vault: Markdown Converter

### Where Modern Sovereignty Meets Timeless Elegance.

Sovereign Vault is a high-performance, **zero-latency** Markdown-to-Document converter. Built with a "Privacy-First" hardened architecture, this tool ensures that your data never leaves your browser.

## 💎 The Zenith Sovereign Experience

This application is designed as a **Digital Vault** for your professional notes and manifestos. It offers an elite, high-contrast environment that prioritizes your data privacy and typographic rhythm.

*   **White-Glove Onboarding:** The system intelligently waits 30 seconds before suggesting a home-screen installation, ensuring you experience the workspace first.
*   **Structural Scroll Hardening:** Both editor and preview panes feature deep bottom buffers (200px) so your text always clears floating action buttons perfectly.
*   **Silent System Status:** No intrusive sync text; the vault communicates its persistent state via a minimal, pulsing emerald indicator dot.
*   **Vector Fidelity:** PDF exports are precision-engineered as vector-text mirrors of the editor, featuring bold black headings for maximum professional impact.

## 🛠 Technical Architecture (Lean & Hardened)

*   **Logic Layer:** Pure TypeScript Regex-based refinement (No external AI calls).
*   **UI/UX:** High-Contrast "Obsidian" Aesthetic using Tailwind CSS.
*   **Typography:** Base64-embedded Virtual File System (VFS) for Inter and JetBrains Mono.
*   **Persistence:** Local-only storage via `IndexedDB` (Dexie.js).
*   **Binary Engine:** Client-side `jsPDF` and `docx` generation.

## 🔒 Privacy Manifesto

1. **Zero External Calls:** No Google Analytics, no AI APIs, no telemetry.
2. **Volatile Processing:** Documents are refined and converted in browser RAM.
3. **Local Sovereignty:** You own the fonts, the logic, and the data.
